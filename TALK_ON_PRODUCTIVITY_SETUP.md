
# Most Important Basics
- These changes require minimal setup and provide a large productivity gain; They work on basically all systems

- Use a clipboard manager (win+v works out of the box on windows; win+v works out of the box on KDE plasma; on Ubuntu I like diodon: set up with sudo apt install diodon and set hotkey win+v to use it)

- Use hotkeys for most used programs/websites (ctrl+shift+alt+n for notes; ctrl+shift+alt+n

- ctrl+alt+t for terminal in most linux distributions

- ctrl+t for new tab in firefox; ctrl+shift+t / ctrl+shift+n to reopen a tab/window

- Use nice keyboard controls (hold ctrl+[Arrow] to jump through words; hold ctrl+backspace/del to delete word)

- use ctrl+c / ctrl+v / ctrl+shift+v (duh)
